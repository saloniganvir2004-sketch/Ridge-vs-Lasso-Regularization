# 📊 Effect of Regularization: Ridge vs Lasso

## 📌 Overview
This project analyzes the impact of Ridge (L2) and Lasso (L1) regularization on regression models using Python and Scikit-learn.

## Tools & Technologies
- Python
- NumPy
- Pandas
- Matplotlib / Seaborn
- Scikit-learn

## Working
- Implemented Ridge and Lasso regression models
- Compared coefficient values and model performance
- Analyzed how regularization reduces overfitting
- Visualized results using graphs

## Key Insights
- Ridge reduces coefficient magnitude but retains all features  
- Lasso performs feature selection by shrinking some coefficients to zero  
- Both techniques improve model generalization  

## How to Run
1. Install required libraries  
2. Open the notebook  
3. Run all cells  

## Conclusion
Ridge is useful when all features are relevant, while Lasso helps simplify models by selecting important features.
